# PlaniFun
Réalisation d'un logiciel de planification de tâches, tout en utilisant des principes SOLID et de différentes patrons vu en cours d'Architecture Logiciel.

On peut réaliser les actions suivantes :

- La création d'une liste de tâches
- L'ajout d'une nouvelle tâche quelle que soit son type dans une liste de tâches existante
- La sauvegarde d'une liste de tâches créée depuis l'application sous forme de fichier XML
- Le chargement d'une liste de tâches préalablement sauvegardé dans l'application
- La lecture de l'aide d'utilisation du logiciel
- Connaitre l'avancée d'une tâche en cliquant dessus
